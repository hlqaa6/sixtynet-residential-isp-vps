## 原生IP、住宅IP、双ISP，SixtyNet 卖的是哪一种

原生 IP 指 IPv4 的 WHOIS 注册信息、ASN 归属和地理位置标注都指向美国本土 ISP，在 MaxMind、IP2Location 这类数据库里显示为真实的美国运营商，而不是机房批量广播出来的地址。它影响的是平台对账号的信任度：流媒体解锁、TikTok 开播、Google 与 Facebook 广告账户、Amazon 店铺注册，机房 IP 在这些场景里更容易被拦。

SixtyNet 在原生 IP 之上多走了一步。它的住宅系列把 IP 落在 Cox Communications、Wave Broadband（Astound）这类美国家宽运营商的地址段里，ipinfo 会显示双ISP 属性。2025 年 10 月的一篇第三方测评测过 Cox 段的机器，结论是 IPv4 为原生美国 IP、带家宽属性、流媒体检测基本全绿。

同一篇测评记录了路由走向：电信去程走 CN2 直连洛杉矶，联通去程直连后接 GTT 再接 Cox，移动去程直连移动洛杉矶节点；回程电信和移动走 CN2，联通走 AS10099 加 AS9929。联通用户体验最好，原因就在这里。那台机器官方屏蔽了 PING，也不支持 IPv6，测评里的延迟数据因此没能给出。

## 80/443 端口：这条限制决定你能不能买

官网在住宅 IP 产品下写得很直接：由于 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。Pro 系列同样如此，而且更进一步，默认拒绝所有外部探测和扫描，没有中继 IP，只有白名单里的地址或做过端口转发的设备才能连上。

对两类人影响完全不同。

做账号和流媒体的人不受影响。TikTok 养号与开播、ChatGPT 和 Claude 的 API 调用、Netflix 与 Disney+ 观看、远程桌面、代理落地，走的都不是 80/443，端口封不封无所谓，反而因为拒绝扫描让 IP 更安静。

要建站的人直接出局。任何需要域名解析到 80/443 的站点、面板、反代都跑不起来，装宝塔也没用。官网上高防系列和大硬盘系列的页面没有标注端口限制，但也没有明确写"开放 80/443"。如果你买这台机器就是为了建站，下单前用工单确认端口策略，或者先用下面这几个官网公布的测试地址验证连通性：Cox 段 24.249.245.68、Wave 段 104.202.107.4、高防与大硬盘系列 172.247.36.5。

同样的钱，配置可以完全一样。住宅 STARTER 月付 $15，加双ISP 是 $20；高防 STARTER 月付 $20，2 核 2G 40G NVMe、5TB、10Gbps 三项参数一字不差，多出来的是 1Tbps 直连防御和去程 163 高防直连。你要是并不需要住宅 IP 属性，这 $5 花在防御上更实在。

## Pro 系列贵在哪里，又麻烦在哪里

Pro 系列用的是 Cox Communications 住宅 IP，回程走联通 AS9929 优化。$35/月 的入门档和住宅 MICRO 同价，但配置只有 2 核 2G 40G，流量也只有 5TB。多付的钱买的是 IP 属性和线路，不是硬件。

麻烦在访问方式。Pro 系列没有中继 IP，服务默认对外完全不可见，你必须先把自己的固定 IP 加进白名单，或者提前配好端口转发，否则付完钱连 SSH 都进不去。官网把这称为"最高安全性"，实际体验就是：换网络环境、换宽带、IP 变了，机器就失联，得回面板改白名单。

还有一条藏在产品说明里：Pro 系列的退款只退到网站余额，不原路退回支付渠道。买之前想清楚，这笔钱进去就只能在站内循环。

## FAQ

**原生 IP 和双ISP 差在哪？**

原生指 IP 的注册信息和归属在美国 ISP 名下。双ISP 是 ipinfo 这类数据库把同一个 IP 同时归到两个运营商，通常出现在家宽段，平台侧看起来更接近真实用户。单ISP 的住宅 IP 也能用，双ISP 是每月加 $5 的可选项，不是独立套餐。

**能解锁 Netflix 吗？**

2025 年 10 月的第三方测评在 Cox 段上测出流媒体基本全绿。平台的封禁名单是动态更新的，商家不承诺长期可用。买之前用官网给的测试地址先看，或者先买最短周期。

**80/443 封了还能干什么？**

TikTok 养号与开播、ChatGPT 与 Claude 的 API 调用、流媒体观看、远程桌面、代理落地，这些都不走 80/443。不能做的是需要域名直接解析到这两个端口的网站和面板。

**支持 IPv6 吗？**

不支持。

**流量用超了会怎样？**

公开页面没有给出住宅系列的流量超额处理规则，下单前在购物车页或工单确认。这一点别默认成"限速不断机"，各家策略不一样。
